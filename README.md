## How to Compile and Run

1. In pgAdmin, create a database called `students_db`.
2. Run `table.sql`, then `data.sql`, in the Query Tool on `students_db`.
3. Install the driver: `pip install psycopg2-binary`
4. In `students.py`, change `password` in `get_connection()` to your PostgreSQL password.
5. Run the program: `python students.py` (Python doesn't need compiling)
